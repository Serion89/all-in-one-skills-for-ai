# ⚡ All-in-One Skills for AI (`all-in-one-skills-for-ai`)

> **"Make your AI an absolute unit of an engineer."** 🚀

A comprehensive, curated repository of **54 production-grade AI Agent Skills** compliant with the open [`SKILL.md`](https://agentskills.io) standard. Compatible across **Claude Code, Cursor, Windsurf, GitHub Copilot, Antigravity, Cline, and Codex**.

---

## 🌟 What's Included?

This bundle solves the five biggest problems with AI coding assistants:
1. **Token Bloat & Fluff** $\rightarrow$ High-speed, terse communication (saves 65–75% tokens).
2. **Over-Engineering & Dependency Addiction** $\rightarrow$ YAGNI philosophy, ladder of laziness, surgical edits.
3. **Generic "AI Slop" UI** $\rightarrow$ Professional design systems, intentional typography, color theory, spatial rhythm.
4. **Vibe Coding & Context Loss** $\rightarrow$ Persistent markdown memory (Manus-style), strict brainstorming, design spikes, TDD.
5. **Infrastructure Blindspots** $\rightarrow$ Enterprise audits for Docker, Kubernetes, Terraform, Databases, and SRE incident response.

## 🗂️ Categorized Skill Directory (54 Skills)

### 1. ⚡ Token Efficiency & Anti-Over-Engineering
*Eliminate verbosity, cut token burn, and enforce the "Lazy Senior Developer" philosophy.*

| Skill | Description |
| :--- | :--- |
| **`caveman`** | Ultra-terse, fluff-free communication style. Strips filler words while preserving 100% technical substance. |
| **`caveman-commit`** | High-density, conventional git commit messages with zero conversational padding. |
| **`caveman-compress`** | Summarizes large contexts, logs, or error traces into dense, token-minimal technical briefs. |
| **`caveman-optimize`** | Audits prompts and workflows to minimize token usage across multi-turn agent sessions. |
| **`ponytail`** | Stops over-engineering via the **Ladder of Laziness**: YAGNI $\rightarrow$ Reuse $\rightarrow$ Stdlib $\rightarrow$ Native platform $\rightarrow$ Dependency. |
| **`ponytail-audit`** | Detects unnecessary dependencies, oversized packages, and over-abstracted wrappers. |
| **`ponytail-debt`** | Identifies technical and architectural debt before adding new abstractions. |
| **`investigate-first`** | Forces deep root-cause inspection before touching code or proposing fixes. |
| **`lean-build`** | Build pipelines and prototypes with absolute minimum boilerplate and maximum leverage. |
| **`safe-refactor`** | Step-by-step refactoring rules with regression barriers and backward compatibility checks. |
| **`surgical-patch`** | Produces minimal, exact diffs instead of rewriting whole files or functions. |
| **`verify-and-stop`** | Enforces stopping criteria once requirements are proven green rather than continuing to fiddle with code. |

## 🚀 Quick Setup & Installation

### Option A: Install for Claude Code
To link all skills into your global Claude Code environment:
```bash
# Clone the repository
git clone https://github.com/Serion89/all-in-one-skills-for-ai.git

# Copy or link skills to ~/.claude/skills
cp -r all-in-one-skills-for-ai/skills/* ~/.claude/skills/
```

### Option B: Install for Antigravity / Gemini CLI
```bash
# Windows PowerShell
Copy-Item -Path "all-in-one-skills-for-ai\skills\*" -Destination "$HOME\.gemini\config\skills\" -Recurse -Force

# Linux / macOS
cp -r all-in-one-skills-for-ai/skills/* ~/.gemini/config/skills/
```

### Option C: Use in Any Project (Cursor, Windsurf, Cline)
Drop any skill directly into your project's `.agents/skills/` or `.cursor/rules/`:
```bash
mkdir -p .agents/skills
cp -r path/to/all-in-one-skills-for-ai/skills/frontend-design .agents/skills/
cp -r path/to/all-in-one-skills-for-ai/skills/planning-with-files .agents/skills/
cp -r path/to/all-in-one-skills-for-ai/skills/caveman .agents/skills/
```
